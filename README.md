# MiniJavaCompiler
Compiler for a restricted version of Java. Implements automated analysis on Java source code and generation of intermediate code. 

Some limitations of this modified version of Java (hereby denoted as MiniJava) include:
 - No exceptions.
 - No threading.
 - Stricter syntaxis.
 - No operator precedence.

Compiler builds ASTs (Abstract Syntactic Trees) and symbol table to represent the structure and meaning of uploaded MiniJava program.
